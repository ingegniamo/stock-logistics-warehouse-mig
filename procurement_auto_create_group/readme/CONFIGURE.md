1.  Go to *Inventory / Configuration / Settings*, check the option
    'Multi-Step Routes' and press the 'Save' button.
2.  Activate the developer mode.
3.  Go to *Inventory / Configuration / Warehouse Management / Routes* and
    select the route you want to change. Select the rule you wish to
    change and tick 'Auto-create Reference'.

Odoo 19 note: up to 18 the checkbox appeared only after setting
'Propagation of Procurement Group' to 'Propagate'. Odoo 19 removed that
option from the rule, so the checkbox now stands on its own, next to
'Propagate Cancel and Split'.
